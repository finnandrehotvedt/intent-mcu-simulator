# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow for this repository:
open the **Security** tab, select **Advisories**, then choose **Report a
vulnerability**. Include the affected revision, a minimal reproduction, the
expected impact, and any suggested mitigation.

Do not include credentials, personal data, active exploit payloads, or details
about unrelated systems in a public issue.

## Supported source

Security fixes target the latest revision on the default branch. This public
source release does not include or operate the isolated compiler service,
toolchain image, deployment environment, user accounts, analytics, or a live
AI service.
