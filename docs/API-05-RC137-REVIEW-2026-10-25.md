# RC137 browser-session review — 2026-10-25

This dated release copy reconciles the approved 24 October recording with the
reviewed RC137 source. The recording remains approved, unchanged historical
media for the AVR workflow it shows. Its older read-only wording is not current
authority for RC137 and must not be used to imply that the other profiles
remain read-only.

RC137 allows an explicitly edit-enabled pairing to reach the existing
canonical editor for each of the four exact profiles. AVR retains its existing
catalogue and authored-label rules. Pico, ESP32-C3 and STM32 remain constrained
to one fixed controller, one resistor and one LED, their exact named pins,
bounded properties and profile-owned electrical validators. No browser-session
command can Build, Run, compile, upload, access a device or create a worker.

Independent Windows/Chrome review accepted commit
`9974fde7a560b5fccbad3c2848c97d911529cb01`. One persistent client and one
pairing remained usable across chat turns, more than 71 requests and 15 minutes
18 seconds. The review covered all four manual and API journeys, named-net
disconnect/reconnect, property rendering, Save/Open/reload and exact Undo. A
13-request burst produced bounded rate-limit responses; after an 11-second
cooldown, inspect and exact Undo succeeded without re-pairing, sequence guessing
or a blind mutation retry. Revoke and owner close both retired authority with
`API_AUTH_REQUIRED`.

This is source review evidence, not deployment evidence. Public version,
rollback image, counters and service state remain owned by the separate
deployment checkpoint. The approved recording itself was not edited,
regenerated or republished by RC137 release preparation.
