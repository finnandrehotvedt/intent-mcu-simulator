The workbench keeps project ownership with the learner and rejects ambiguous electrical plans.

Where is my project saved?

Save project writes a file chosen by your browser or operating system. Open project reads that file back. Browser recovery is separate and is not a cloud backup.

Why is Build blocked?

The circuit and firmware pin use must agree. Check diagnostics for missing ground, reversed polarity, absent current limiting, reused pins, output conflicts, or an unsupported topology.

How does Prompt Bridge work?

It creates portable text for a tool you choose; the site has no live AI connection. Pasted results have no drawing authority until strict schema, pin, and electrical checks accept them.

Can it upload to a physical board?

No. This release compiles and runs a tested educational AVR subset in virtual hardware. It does not access USB or Serial devices and is not electrical-safety certification.

Why do some controllers say Preview only?

Only ATmega328P has a public compiler and verified execution path. The other selector entries expose exact status and bounded private evidence, but disable project Open, Build, Run, private endpoints, and runtime creation. A preview or private fixture is never presented as public runtime support.

Where can I report a problem?

Use the public repository issue templates for ordinary bugs. For a suspected vulnerability, follow the repository's private security-reporting instructions.
