Where is my project saved?

Save project writes a local file; your browser or operating system chooses the location. AVR uses the native file picker when available and otherwise requests a deterministic .intent-mcu.json download. Pico directly downloads .intent-mcu.json; ESP32-C3 and STM32 directly download .json. Open project reads the chosen file. Browser recovery is separate and is not a cloud backup.

Why is Build blocked?

The circuit and firmware pin use must agree. Check diagnostics for missing ground, reversed polarity, absent current limiting, reused pins, output conflicts, an unsupported topology, or a cable endpoint that is still being chosen. Finish the cable or press Escape, then Build fresh.

How do I repair a bounded controller cable?

For Pico, ESP32-C3 or STM32, delete a cable and activate two compatible free named pins to recreate it. To move one end, select the cable, choose Reconnect endpoint, choose the connected endpoint, then its compatible free target. Save/Open retains the authored topology but never restores executable authority.

How do I restore a missing resistor or LED after Open?

Open keeps an intentionally incomplete circuit but starts with no Undo history. In Supported parts, choose Add missing part. The original stable ID returns in a safe position and no cable is inferred. Reconnect the exact named-pin series path, resolve any COMPONENT_PROPERTY_ELECTRICAL_LIMIT by selecting a safe resistance/LED-colour pair, then Build fresh. Unsupported parts and wrong-controller files reject without replacing the current project.

What is stored in a project file?

Project name, bounded source, controller profile, supported component properties, layout, rotation and authored named-pin wiring are data. Firmware, UF2, flash, ELF, runtime sessions, capabilities and secrets are excluded. A malformed, oversized, wrong-profile or unsupported project is rejected atomically; repeated Open does not duplicate parts or wires.

How does the thermostat verdict work?

Each scenario resets to virtual cycle 0, applies the ideal A1 temperature and D2 button inputs, and observes between 160 and 350 virtual milliseconds. A pass requires the executed D13 pin, matching UART text and complete ordered input evidence. Missing, late or contradictory evidence never passes. The saved compatibility reference contains hashes and sizes only; it is not executable authority. Open always requires a fresh source-bound Build.

How does Prompt Bridge work?

It creates portable text for a tool you choose; the site has no live AI connection. Pasted results have no drawing authority until strict schema, pin, and electrical checks accept them.

Can it upload to a physical board?

No. This release runs tested educational AVR, Pico, ESP32-C3, and STM32F429ZI subsets in virtual hardware. It does not access USB or Serial devices and is not electrical-safety certification.

What does STM32 support?

One bounded STM32F429ZI C11 grammar compiles in the fixed ARM toolchain and executes in actual Renode 1.17.0. Only PB0 output, USART3 uppercase text, strict ELF admission and reset replay are claimed. The named PB0/resistor/LED/GND teaching path is editable and validated, but remains an ideal circuit rather than physical or analogue equivalence.

Where can I report a problem?

Use the public repository issue templates for ordinary bugs. For a suspected vulnerability, follow the repository's private security-reporting instructions.
